# puls3_client

The client of the [puls3](https://github.com/Zer0-Knowledge-Hack/puls3) API,
generated by [Serverpod](https://serverpod.dev) from `puls3_server`.

**Use [`puls3_sdk`](https://pub.dev/packages/puls3_sdk) instead.** It wraps this
client with typed calls for the catalog, hires and the Studio, and it never
signs or submits a transaction. This package exists because `puls3_sdk` needs
it from pub.dev.

The code under `lib/src/protocol/` is generated: do not edit it. A release of
this package follows the server it was generated from, and it pins the exact
Serverpod version of that server. See
[releasing](https://github.com/Zer0-Knowledge-Hack/puls3/blob/main/docs/sdk/releasing.md).
